## Features

- Advanced VBA and C# automation macros optimized for rapid feature creation, batch file conversion (SLDPRT/SLDASM to STEP/IGES), and professional assembly management workflows.
- Custom parametric part and assembly templates (.prtdot/.asmdot) with pre-configured design tables, global variables, and standardized material libraries for enhanced engineering consistency.
- Quick-switch macros and custom CommandManager configurations for seamless navigation between Part, Assembly, and Drawing environments.
- Pre-configured drawing templates (.drwdot) and sheet formats with automated Bill of Materials (BOM) generation, revision table tracking, and GD&T annotation routines.
- Comprehensive documentation and step-by-step setup guides for all included tools, macro files, and modules.
- Integration examples and bridge scripts for third-party PLM/PDM ecosystems (e.g., SolidWorks PDM, Siemens Teamcenter, Autodesk Vault) and rendering tools (e.g., KeyShot, Visualize).
- System resource optimization configs for faster large-assembly regeneration, reduced RAM usage, and optimized GPU acceleration (RealView Graphics) during complex surface modeling.
- Ready-to-use automated interference detection, mass property calculation, and design validation routines with smart error logging capabilities.

## Requirements

- Windows 10/11
- Installed SolidWorks (Professional or Premium edition recommended for advanced routing, sheet metal, and PDM integration features)

## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1`) to integrate the custom VBA macros, templates, and CommandManager configurations directly into your SolidWorks `macro` and `template` directories. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced API usage, refer to the `GUIDE.md` file included in the archive.
